# استوديو الغسق (Twilight Studio)

تطبيق Flutter عربي (RTL) لتحويل الفكرة إلى فيلم بالذكاء الاصطناعي، من التأليف الروائي حتى خطة إنتاج الفيديو.

## الأقسام

| القسم | المحتوى |
|---|---|
| **التأليف** (الأولوية) | الفكرة (Premise, Logline, الثيمة، النوع، النبرة، المنظور)، الشخصيات (الرغبة، الحاجة، الجرح، العيب، القوس، الصوت)، الفصول مع محرر وعداد كلمات، اختيار الهيكل السردي (ثلاثي، رحلة البطل، القصة القصيرة)، وقواعد الكتابة. |
| **المشاهد** | مشروع تجريبي كامل «خريطة الغسق الأخير»: 4 مشاهد بالأقسام الخمسة، شريط زمني، بحث، مفضلة، دليل الاتساق، ونسخ بنقرة. |
| **الإنتاج** | البروميت الرئيسي (ثلاثة أجزاء)، مراحل الصورة والصوت والمؤثرات، وتتبع التقدم. |

في كل شاشة أزرار «نسخ بروميت» تولّد نصاً جاهزاً للصقه في Claude أو ChatGPT مبنياً على بيانات قصتك: تطوير الفكرة، تعميق الشخصية، خطة الفصول، كتابة الفصل، تحسين النص، والتحويل إلى مشاهد فيديو.

كل ما تكتبه يُحفظ على الجهاز تلقائياً ولا يخرج منه.

## الرفع إلى GitHub وبناء APK (بدون تثبيت Flutter)

1. أنشئ مستودعاً جديداً على GitHub (مثلاً `twilight-studio`).
2. ارفع محتويات هذا المجلد كلها. **انتبه:** السحب والإفلات في المتصفح يتجاهل المجلدات المخفية، لذلك إن لم يظهر `.github/workflows/build.yml` بعد الرفع فأنشئه يدوياً من:
   `https://github.com/<user>/<repo>/new/main?filename=.github/workflows/build.yml`
   والصق محتوى الملف ثم Commit. وإن كان Git مثبتاً فالأسهل:
   ```bash
   git init && git add . && git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/<user>/<repo>.git
   git push -u origin main
   ```
3. افتح تبويب **Actions** ثم **Build APK** ثم **Run workflow** (يعمل أيضاً تلقائياً مع كل push على main).
4. بعد نحو 6 دقائق افتح التشغيل المكتمل، وانزل إلى قسم **Artifacts** في آخره، ونزّل `twilight-studio-apk` (ملف ZIP)، وفك الضغط لتجد `app-release.apk`.
5. انقل الملف إلى الهاتف وثبّته (فعّل «التثبيت من مصادر غير معروفة»).

## ملاحظات تقنية

- مجلد `android/` لا يُرفع؛ الـ workflow يولّده بـ `flutter create` ثم يشغّل `tool/setup_android.py` الذي يضبط اسم التطبيق والأيقونة وإعدادات الأمان.
- إصدار Flutter ثابت: `3.27.4`.
- الـ APK يُوقَّع بمفتاح debug جديد في كل بناء، فإذا فشل التثبيت فوق نسخة أقدم فاحذف القديمة أولاً.
- للتشغيل المحلي: `flutter create --platforms=android . && python3 tool/setup_android.py && flutter run`.
- الاختبارات: `flutter test`.

## بنية المشروع

```
lib/
  main.dart               نقطة الدخول والتنقل
  theme.dart              ألوان Teal & Amber
  models/                 نماذج المشاهد والقصة
  data/                   بيانات المشروع التجريبي والبروميت الرئيسي وقوالب الهياكل
  services/               الحفظ المحلي وتوليد البروميتات والتصدير
  screens/                الشاشات
  widgets/                عناصر مشتركة
tool/setup_android.py     ضبط مشروع أندرويد المُولَّد
docs/MASTER_PROMPT.md     البروميت الرئيسي (مصدر lib/data/master_prompt.dart)
.github/workflows/        بناء APK
```
